No third-party models, textures or animations are used: no CC0 packs, no Mixamo, no Quaternius, and no Synty (its EULA bans blockchain projects).

Tools: Blender (GPL) and ffmpeg are used only to run the scripts and make previews. Their licenses do not apply to the files they produce. The review renders in `art/renders/size_check.png` use Blender's built-in font for the labels; that image is not a game asset.

If a third-party asset is ever added, record it in the table above with its source URL, author, license (CC0 only for now) and the date it was checked.
