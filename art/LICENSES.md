# Art sources and licenses

Everything in `art/` and every GLB it publishes to `apps/client/public/models/` (`duck.glb`, `duck_anims.glb`, `weapons/rifle.glb`, `weapons/pistol.glb`, `weapons/attach.json`) is original Qwakk work, generated by the Python scripts in `art/blender/`.

| Asset | Source | License |
| --- | --- | --- |
| Duck mesh, rig, skin weights, palette | `art/blender/duck.py`, `rig.py`, `params.py` | Qwakk original |
| Animation clips | `art/blender/clips.py` (authored as code, no capture or third-party clips) | Qwakk original |
| Rifle and pistol | `art/blender/weapons.py` (no real-world brand names or logos) | Qwakk original |
| Doomer beanie | `art/blender/duck.py`, from our own reel design in `marketing/reel/src/parts.tsx` | Qwakk original |

No third-party models, textures or animations are used: no CC0 packs, no Mixamo, no Quaternius, and no Synty (its EULA bans blockchain projects).

Tools: Blender (GPL) and ffmpeg are used only to run the scripts and make previews. Their licenses do not apply to the files they produce. The review renders in `art/renders/size_check.png` use Blender's built-in font for the labels; that image is not a game asset.

If a third-party asset is ever added, record it in the table above with its source URL, author, license (CC0 only for now) and the date it was checked.
