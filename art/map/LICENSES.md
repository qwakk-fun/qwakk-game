# Licenses: WWII map kit

Every asset in `art/map/` and `apps/client/public/models/props/` is original work, generated by the Python scripts in this folder (Blender driven by `blender/*.py`, layout by `layout/*.py`). No third-party models, textures, scans or CC0 bases were used. No Synty assets.

| Asset | Source | License |
| --- | --- | --- |
| All prop meshes, colliders, palette, map_v1 data | Generated by our scripts | Owned by Qwakk |
| Review renders in `renders/` | Rendered from the above | Owned by Qwakk |
| Duck in `street_scene.png` and `scale_duck_at_door.png` | `art/export/duck.glb`, imported read-only | Owned by Qwakk (art workstream) |
| Label text in the review renders | Blender's built-in UI font | Shipped with Blender; used only in review images, never in the game |
| Build tool only: glTF Transform 4.4.2 (`@gltf-transform/core`, `extensions`, `functions`) | npm, pinned in `tools/package.json` | MIT; runs at build time, nothing from it ships in the GLBs |
| Build tool only: meshoptimizer 1.0.1 (encoder) | npm, pinned in `tools/package.json` | MIT; the GLBs use the open `EXT_meshopt_compression` format |
| Runtime decoder: three's `meshopt_decoder.module.js` | already part of `three` 0.186.1 in the client | MIT (three.js) |

Content rules followed: fictional factions only (Pond Brigade, Grey Gull Corps), no real national, Nazi or unit insignia, no real-world text on signs, no brand or token logos.
